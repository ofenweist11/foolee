Norwegian sub-threshold

Méthode « Sirpoc » : 2 à 3 séances par semaine juste sous le seuil (lactate ~2–3 mmol), récup courte de 60 s, tout le reste en endurance très facile + une sortie longue. La séance doit sembler contrôlée, jamais à fond.

Plafonds FC indicatifs : quelques bpm sous ta FC seuil, plus bas quand les répétitions s'allongent. Si la FC dérive au-dessus, ralentis.

Exporter depuis Garmin Connect

Une activité : connect.garmin.com → Activités → ouvre l'activité → ⚙ (en haut à droite) → Exporter l'original (un .zip contenant le .fit). Importe le .zip tel quel.

Tout l'historique : Garmin → Compte → Paramètres de confidentialité → Exporter vos données. Dans l'archive reçue par e-mail, les .fit sont dans DI_CONNECT/DI-Connect-Uploaded-Files (des .zip, à importer directement).

La synchronisation automatique demande un serveur (Garmin n'ouvre pas son API aux sites personnels) : prévu dans une prochaine étape.

Efficacité aérobie

Vitesse ÷ FC moyenne sur tes sorties faciles (m/min par battement). Si la courbe monte, tu cours plus vite pour le même effort cardiaque.

Temps par zone · 4 semaines

Zones Karvonen de l'onglet Performances. Repère : environ 80 % en Z1–Z2.

Meilleurs efforts

Segments les plus rapides trouvés dans tes sorties (pauses incluses). Ce sont des minimums : une course à fond sera meilleure.
