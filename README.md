# Hub Foulée

Hub course à pied : VDOT, allures, VO2max & chronos, constructeur de séances (dont Norwegian sub-threshold), parcours OpenStreetMap avec export GPX.

Site statique, sans serveur : tout tient dans `index.html`. Les données (références, séances, parcours) restent dans le navigateur.

## Services utilisés (gratuits, sans clé)
- Cartes : OSM France, OpenStreetMap, CyclOSM, OpenTopoMap
- Itinéraires piétons : OSRM FOSSGIS (routing.openstreetmap.de)
- Recherche d'adresse : Nominatim
- Altitude : Open-Meteo
